# Workspace Rules and Memory: Resume & Career Intelligence

## 1. Absolute Truth and Verification (Zero Fabrication, Zero Extrapolation)

**Core Mandate:** Under no circumstances should an agent ever invent, extrapolate, or assume a technology, framework, tool, library, or certification just because a Job Description (JD) requests it.

- **Strict Backend Positioning:** Gabriel's core expertise is strictly Backend Software Engineering. Drop any React or frontend mentioning across resumes, summaries, tailored outputs, interview scripts, and ATS reports. Never position or tailor Gabriel for frontend or full-stack roles.
- **Exclusive Truth Sources:** Only technologies and accomplishments explicitly documented in `main.tex`, `achievements/ACHIEVEMENTS.md`, or verified in repository code may appear in tailored resumes, cover emails, interview answers, or ATS reports.
- **Unverified Terms Are Gaps:** If a JD asks for a skill not backed by verified evidence (e.g., React, Next.js, Vue, Angular, JWT, Express, Jest, Babel, Java, Go, Kafka, .NET, Terraform), it must be reported plainly as a **Real Gap** or excluded. Never add it to satisfy an ATS score.
- **Specific Verified Ground Truths:**
  - **Back-End Runtimes & Frameworks:** Python (Django, FastAPI), PHP (Symfony), Node.js / TypeScript (NestJS, Fastify). *(NOT Express, NOT React, NOT Next.js).*
  - **Databases & Caching:** PostgreSQL, MySQL, Redis (Cache-Aside, distributed rate limiting).
  - **DevOps & Infrastructure:** Docker, Kubernetes (pod lifecycle, ConfigMaps/Secrets, ingress TLS), GitHub Actions, CI/CD, Nginx gateway hardening.
  - **Testing:** pytest (Full Cycle production, pytest-xdist), automated CI testing. *(NOT Jest).*
  - **Authentication & Security:** Session cookies, security headers, token management, Nginx transport hardening. *(Do not write JWT unless explicitly confirmed in code).*
  - **Commercial Production Experience:** 5+ years in tech, with 3+ years dedicated to backend software engineering (Full Cycle: Python/Django, PHP/Symfony, PostgreSQL, MySQL, Redis, Docker, CI/CD).
  - **Personal Deployed Projects:** FastAPI, NestJS, PostgreSQL, Redis, Model Context Protocol (MCP), multi-agent workflows.

## 2. Style and Output Guardrails
- **No Em Dashes or En Dashes:** Never use `—` or `–` in any user-facing text, reports, emails, connection notes, or tailored LaTeX documents. Gabriel considers them an AI tell. Use commas, colons, parentheses, or periods.

## 3. Base Source is Always `main.tex` (Zero Context Leakage, Zero Skill Bloat)
- **Always Anchor to `main.tex`:** When tailoring, ALWAYS copy directly from `main.tex` as the base template. Never reuse or carry over skills blocks from previously tailored files in the context window.
- **No Granular Skill Inflation:** Keep the Skills section clean, concise, structured like `main.tex`, and focused exclusively on backend engineering, infrastructure, databases, and architecture.
